What is a SCADA?

Imagine operating the Death Star. Thousands of doors. Millions of sensors. Thousands of motors. Cooling systems. Vacuum systems. Power supplies. Particle accelerators. Cryogenic pumps. Radiation monitors.

Would you control all of this manually? Obviously not. Neither does any modern facility — CERN, NASA, power grids, water treatment plants. All automated.

Slide 2 — "Imagine Operating the Death Star."

SCADA stands for Supervisory Control And Data Acquisition. But forget the acronym. A SCADA is the nervous system of your installation. Invisible. Everywhere. Connecting everything. When it works — nobody notices. When it fails — everyone notices. Sound familiar? That's the Force.

Slide 3 — "SCADA. The Force of Your Facility."

Layer 1 — The Droids

Droids do exactly two things. That's it. Just two: they observe, or they act.

In the real world, this is your sensors, your motors, your valves, your industrial controllers. One sensor checks if a pipe is too hot. Another one measures pressure. Another controls a pump. Just like a Droid reporting back to base — "All clear in corridor seven."

Slide 5 — "Layer 1: On the Ground — The Droids."

They're not smart. They don't think. But without them — you're flying completely blind through the asteroid field. In EPICS, each measurement is called a Process Variable (PV). In TANGO, it's called an Attribute. Same Droids — different name tags.

Page 6

Layer 2 — The Holographic Network

Remember that flickering blue hologram? The Emperor calling Darth Vader from across the galaxy? That's your communication bus. The invisible highway that carries information between the ground level — your sensors and machines — and the brain of the system.

Data goes up ↑. Orders go down ↓. All day. Every second. Never stopping.

Slide 6 — "Layer 2: The Holographic Network."

If it fails? It's like destroying Alderaan. Everything stops. Instantly. No data. No control. No nothing. In EPICS, the protocol is called Channel Access (or its modern version PV Access). In TANGO, it started with CORBA and evolved toward ZeroMQ.

Respect the bus. It's more important than it looks.

Page 7

Layer 3 — The Emperor's Throne Room

The Emperor sees everything. Knows everything. Decides everything. That's your SCADA server. Darth Vader executes. Immediately. No discussion. That's your real-time supervisor.

In EPICS, this layer is handled by the IOC (Input Output Controller). In TANGO, by the Device Server — which adds the concept of Commands.

Slide 7 — "Layer 3: The Emperor's Throne Room."

This layer manages alarms ("Luke is too close to Reactor 4"), dashboards (all blinking screens, all the time), archives (like the Jedi Archives — everything recorded), and automation (Order 66 — one command, many consequences).

Slide 9 — "What You Now Know, Padawan."

⚡ A SCADA is not just software. It's hardware, network, logic, and humans — all working together.

Glossary

Every technical term used in this guide — with plain-English definitions and links back to where they appear.

SCADA
Supervisory Control And Data Acquisition
The software and hardware architecture that monitors, controls and manages all equipment in an industrial or scientific facility. Think of it as the nervous system of your installation.
↑ See in guide
PV
Process Variable
In EPICS, a PV is a named data point representing one measurement or control value in the system — like a temperature, a pressure, or a motor speed. Each PV is accessible either in read or in write.
↑ See in guide — Layer 1
Attribute
TANGO equivalent of a PV
In TANGO, an Attribute is the equivalent of an EPICS Process Variable. It represents a value exposed by a Device Server — readable or writable depending on the configuration.
↑ See in guide — Layer 1
IOC
Input Output Controller
The core software unit in EPICS. An IOC is a program that runs on a server and acts as the bridge between the physical hardware and the rest of the control network. It exposes Process Variables either in read or in write.
↑ See in guide — Layer 3
Device Server
TANGO equivalent of an IOC
The core software unit in TANGO. Like an IOC, a Device Server exposes Attributes in read and write. It also exposes Commands — reusable actions that can execute simple operations or complex sequences.
↑ See in guide — Layer 3
Command
TANGO specific concept
In TANGO, a Command is an action exposed by a Device Server. It can be a simple write ("Turn on"), or trigger a complex sequence of operations across the system — like Order 66.
↑ See in guide — Layer 3
Communication Bus
Industrial network layer
The network infrastructure that carries data between field devices (sensors, actuators) and the supervision layer. Data flows up, orders flow down. If it fails, everything stops — like destroying Alderaan.
↑ See in guide — Layer 2
Channel Access
EPICS communication protocol (classic)
The original EPICS network protocol, in use since the late 1980s. Works on a publish-subscribe model: a client subscribes to a channel and receives updates automatically when a value changes.
↑ See in guide — Layer 2
PV Access
EPICS communication protocol (modern)
The modern successor to Channel Access. Faster, more flexible, and better suited for complex data structures. Think of it as upgrading from a flickering blue hologram to full HD transmission.
↑ See in guide — Layer 2
CORBA
Common Object Request Broker Architecture
The middleware used by TANGO for communication in its earlier versions. Works on a polling model: the client regularly asks the server for the current value. Reliable and structured, but slower for real-time responsiveness.
↑ See in guide — Layer 2
ZeroMQ / ZMQ
Zero Message Queue
The modern messaging library used by TANGO for event-driven communication. Instead of polling, the server pushes updates the moment a value changes. Pure reactivity — like a direct Force connection between sender and receiver.
↑ See in guide — Layer 2
PLC
Programmable Logic Controller
A rugged industrial computer used to control physical processes in real time. PLCs are the workhorses of the hardware layer — powerful, robust, and mission-specific. The AT-AT walkers of the SCADA world.
↑ See in guide — Layer 1
HMI
Human-Machine Interface
The visual interface that operators use to monitor and control the system. The blinking screens in the Death Star control room. In the EPICS world: Phoebus, CS-Studio. In the TANGO world: Taurus.
↑ See in guide — Layer 3
EPICS
Experimental Physics and Industrial Control System
An open-source control system framework widely used in particle accelerators and scientific facilities worldwide — CERN, Fermilab, SNS, and many more. Battle-tested since the late 1980s.
↑ See in guide — What's Next
TANGO Controls
no acronym — it's a dance 💃
An open-source object-oriented control system framework developed at the ESRF (European Synchrotron Radiation Facility) in Grenoble, France. Widely used in European research labs. Very French. Very powerful.
↑ See in guide — What's Next
