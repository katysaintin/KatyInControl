# KATY IN CONTROL — WEBSITE ARCHITECTURE

# OBJECTIVES

The website is designed as:

- a modern educational platform
- a SCADA onboarding portal
- a companion to the podcast
- a documentation hub
- a visual learning platform
- a bridge between EPICS and TANGO communities

The project combines:
- Podcast episodes
- Visual slides
- Static HTML pages
- PDFs
- Technical resources
- Community links
- Historical anecdotes
- Beginner-friendly explanations

# GLOBAL PHILOSOPHY

## Core Principles

- Static website only
- Lightweight architecture
- Fast loading
- Easy maintenance
- GitHub Pages compatible
- Mobile friendly
- Long-term maintainable
- Search-engine friendly
- Highly visual
- Minimal cognitive overload
